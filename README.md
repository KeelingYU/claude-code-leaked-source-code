## 使用原则

1. 只把本仓库当作参考分析材料。
2. 不在 `2.1.88/` 内做源码修改。
3. 新增说明、整理、发布辅助文件时，统一放在 `2.1.88/` 外部。
4. 不直接逐文件复刻实现，优先提炼模块、数据流、权限模型与安全边界。
